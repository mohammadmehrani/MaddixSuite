# Welcome to MaddixSuite Wiki

**MaddixSuite** is a cross-platform system administration toolkit created by **Mohammad Mehrani (Maddix)**. It provides a collection of PowerShell (Windows) and Bash (Linux) scripts for diagnostic, repair, backup, security, optimization, and development tasks.

## Supported Platforms

| Platform | Shell | Requirements |
|----------|-------|-------------|
| Windows 7/8/10/11 | PowerShell 3+ | Administrator privileges |
| Linux (Debian/Ubuntu/Fedora/Arch/openSUSE) | Bash | sudo access |

## Quick Links

- **Run SysAdminSuite (Windows):**
  ```powershell
  irm https://raw.githubusercontent.com/mohammadmehrani/MaddixSuite/main/windows/SysAdminSuite.ps1 | iex
  ```

- **Run SysAdminSuite (Linux):**
  ```bash
  bash <(curl -s https://raw.githubusercontent.com/mohammadmehrani/MaddixSuite/main/linux/SysAdminSuite.sh)
  ```

- **Run Safe Diagnostic (Windows):**
  ```powershell
  irm https://raw.githubusercontent.com/mohammadmehrani/MaddixSuite/main/windows/SafeDiag.ps1 | iex
  ```
